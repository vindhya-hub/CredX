# CredX

Full-stack credit card management app (React, Node.js/Express, PostgreSQL, JWT)
with a hybrid-search virtual assistant. The application lives in
[`CredX-Fintech/`](CredX-Fintech/); see [`CredX-Fintech/README.md`](CredX-Fintech/README.md)
for features, setup, Docker, configuration and secrets, the REST API and the
assistant design.
